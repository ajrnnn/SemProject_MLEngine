## How future contributions appear in this repository

Luiz already has a `SemProject_MLEngine` fork. A team member can make a focused change on a branch in their fork, commit under their own Git identity, then open a pull request into `nimrod-kobia/SemProject_MLEngine:main`. After review and merge, the member's original commits and the pull request will be visible in this submission repository. Other members should follow the same fork-and-pull-request process. Keep the raw Delhi CSV and row-level derived data out of public commits.

Do not create replacement commits under another person's name merely to make a contributor graph look complete. The team's presentation should explain actual work and link to its original evidence.
